📦 Projeto: Aplicações em Python (CLI)

Este repositório contém 5 programas independentes em Python, todos em modo terminal (CLI), com foco em lógica, estruturas de dados e menus interativos.



📘 1. aluno_notas.py — Sistema Escolar (Alunos e Notas)
📌 Descrição

Permite gerir alunos, registar 3 notas por aluno e calcular médias.

⚙️ Funcionalidades

Cadastro de alunos com código automático

Registro de 3 notas por aluno (0 a 20, até 2 casas decimais)

Listagem de alunos com notas e média

Mostrar média geral da turma

Eliminar alunos

Menu interativo contínuo

🧠 Conceitos Utilizados

Tipos de dados: str, int, float, list, dict, None

Estruturas de controle: if, elif, else

Ciclos: for, while

Funções (def)

Tratamento de erros (try/except)

Limpeza de tela (os.system)

▶️ Execução
python aluno_notas.py



📘 2. cantina.py — Sistema de Cantina Escolar
📌 Descrição

Permite gerir reservas de refeições, cancelamentos e faturação mensal por aluno.

⚙️ Funcionalidades

Cadastro de alunos

Ementa fixa (pratos, bebidas e sobremesas)

Fazer reservas por data

Listar reservas de um aluno

Cancelar reservas

Calcular fatura mensal

Menu interativo

🧠 Conceitos Utilizados

Dicionários aninhados e listas

Validação de entradas

Datas com datetime

Ciclos for e while

Funções auxiliares

▶️ Execução
python cantina.py



📘 3. hospitalar.py — Jogo Educativo “Missão Escape Room”
📌 Descrição

Um jogo educativo em Python, com desafios de matemática e palavras, moedas, loja e missões. Não é um sistema hospitalar real, apesar do nome.

⚙️ Funcionalidades

Criação de jogador (moedas, energia, inventário, missões)

Desafios aleatórios:

Matemática

Palavras secretas

Sistema de moedas e penalidades

Loja de itens

Visualização do estado do jogador

Visualização das missões concluídas

Relatório final

Menu interativo com limpeza de tela

🧠 Conceitos Utilizados

Biblioteca random para desafios aleatórios

Dicionários e listas

Funções (def) e reutilização de código

Estruturas condicionais (if/else) e ciclos (while)

Entrada e saída de dados (input / print)

Limpeza de tela (os.system)

▶️ Execução
python hospitalar.py



📘 4. jogo.py — Jogo Educativo Simplificado
📌 Descrição

Versão simplificada do jogo Missão Escape Room, para iniciantes, com menos validações e estrutura mais direta.

⚙️ Funcionalidades

Desafios simples (matemática ou palavras)

Loja básica

Inventário e moedas

Visualização do estado do jogador

Missões e relatório final

🧠 Conceitos Utilizados

Funções simples (def)

Condições if / else

Ciclo while

Listas e dicionários

▶️ Execução
python jogo.py



📘 5. restaurante.py — Sistema de Gestão de Restaurantes
📌 Descrição

Permite cadastrar restaurantes, listar e alterar o estado (ativo/desativado) de cada restaurante.

⚙️ Funcionalidades

Cadastro de restaurantes

Listagem de restaurantes

Ativar / desativar restaurantes

Mostrar estado (Ativado / Desativado)

Menu interativo contínuo

🧠 Conceitos Utilizados

Listas de dicionários

Variáveis booleanas (True/False)

Funções auxiliares

Comparação de strings

Ciclo while com menu

▶️ Execução
python restaurante.py
